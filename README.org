это verilog реализация процессора на архитектуре f32a.

* ISA
процессор это 32-х битный, стековый.
имеются 2 регистра: A, B и 2 стека data stack и return stack.

вершина и 2 элемент data stack будут далее обозначатся за T и S соответсвнно.
вершина return stack будет обозначаться как R.

Список инструкций, их действие и реализацию вы можете найти в секции [[Инструкции]]
* Микрокод
разделяется на 4 типа: переходы, инкремент/декремент, перенос данных, работа с памятью.
тип микрокода определяется по 2 младшим битам.

все номера регистров одинаковы для всех микрокодов. могут иметь одинаковые номера так как не встречаются одновременно ни в одном микрокоде.

- 000: 0
- 001:
- 010:
- 011:
- 100:
- 101:
- 110:
- 111:

** 00 переходы
{n’адрес, 32’маска, 3’регистр}

если значение регистра, выбраного соотвествующим параметром, дает 0 после применения ‘и’ маски, в mc записывается адрес, указанный в микрокоде.

** 01 инкремент/декремент
{2’m_offset_pc, 2’m_offset_dps, 2’m_offset_rsp}

m_offset_pc:
- 00: ничего не делает
- 01: +1
- 10: +4

m_offset_dsp:
- 00: ничего не делает
- 01: +4
- 10: -4

m_offset_rsp:
- 00: ничего не делает
- 01: +4
- 10: -4

** 10 перенос данных
{3’mux_reg_input, 3’mux_reg_output}

** multiply step. +*
T <- T + (if A[0] then S else 0); A <- A >> 1; if T[0] then A[31] <- 1 else A[31] <- 0; T <- T >> 1

#+begin_src text :opcode mul_step
  clear_carry

  if A[0] == 0; goto +*_shift_a
  ALU <- T; ALU <- S; +; T <- ALU
  clear_carry

  +*_shift_a:
  ALU <- A; >>; A <- ALU
  A[31] <- 0

  if T[0] == 0; goto +*_shift_t
  A[31] <- 1

  +*_shift_t:
  ALU <- T; >>; T <- ALU

  goto ifetch
#+end_src

    R <- R - 1
