это verilog реализация процессора на архитектуре f32a.

* Как запускать
Для симуляции я использую iverlog и gtkwave.
Запускаю так: src_sh{iverilog -g2012 -o sim.vvp f32a.v control_unit.v RAM.v ALU.v microcode.v simulation.v && vvp sim.vvp && gtkwave simulation.vcd}

Для синтеза схемы использую yosys + netlistsvg, но, к сожалению, схема не получается до тупости простой.
src_sh{yosys -p 'read_verilog -sv "control_unit.v" "microcode.v" "ALU.v"; hierarchy -check -top control_unit; proc; write_json output.json' && netlistsvg -o output.svg output.json}

* ISA
процессор это 32-х битный, стековый.
имеются 2 регистра: A, B и 2 стека data stack и return stack.

вершина и 2 элемент data stack будут далее обозначатся за T и S соответсвнно.
вершина return stack будет обозначаться как R.

Список инструкций, их действие и реализацию вы можете найти в секции [[Инструкции]]
* Микрокод
разделяется на 4(на основе того откуда мы что-либо записываем).
тип микрокода определяется по 2 младшим битам.

** 00
{4'bus_input_mux_reg, 4'bus_output_mux_reg, 2'ALU1_mux_reg, 2'ALU2_mux_reg, 3'ALU_op}

ALU1 op ALU2 -> ALU_output
bus_input -> bus_output

если ALU_op = +, то устанавливаем carry

ALU1_mux_reg:
 0 - A
 1 - R
 2 - T

ALU2_mux_reg:
 0 - 1
 1 - -1
 2 - S

ALU_op:
 0 - +
 1 - &
 2 - ^
 3 - >>
 4 - <<
 5 - ~

bus_input_mux_reg:
  0 - 0
  1 - 1
  2 - A
  3 - B
  4 - dsp
  5 - mem_in
  6 - pc
  7 - R
  8 - rsp
  9 - S
 10 - T
 11 - ALU

bus_output_mux_reg:
  0 - A
  1 - A[31]
  2 - B
  3 - carry
  4 - cmd
  5 - eam
  6 - mem_address
  7 - mem_out
  8 - pc
  9 - R
 10 - S
 11 - T

** 01
{2'pc_offset, 2'dsp_offset, 2'rsp_offset, 1'mem_read, 1'mem_write}

pc_offset:
 0: ничего
 1: +1
 2: +4

dsp_offset:
 0: ничего
 1: +4
 2: -4

rsp_offset:
 0: ничего
 1: +4
 2: -4

** 10
{9'goto_address, 2'goto_mux_reg, 32'goto_mask, 1'goto_cmd}

goto_mux_reg:
 0 - A
 1 - R
 2 - T

goto_cmd:
 0 - переход на адрес из goto_address
 1 - переход на адрес из opcodes[cmd]

  ALU <- T; ALU <- S; +; T <- ALU
  carry <- 0

  +*_shift_a:
  ALU <- A; >>; A <- ALU
  A[31] <- 0

  if T[0] == 0; goto +*_shift_t
  A[31] <- 1

  +*_shift_t:
  ALU <- T; >>; T <- ALU

  goto ifetch
#+end_src

    R <- R - 1
    p <- <label>
else returnStack.pop()

#+begin_src text :opcode next
  carry <- 0

  if R == 0; goto next_return
  ALU <- R; ALU <- -1; +; R <- ALU

  mem_read
  pc <- mem_in

  goto ifetch

  next_return:
  mem_address <- rsp
  mem_read
  R <- mem_in
  rsp += 4

  goto ifetch
